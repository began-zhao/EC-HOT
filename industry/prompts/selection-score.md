## 内部计算步骤（只在心里完成，不要输出）

### 一、识别事件与内容类型

先用一句话确认“谁，在什么时候，做了什么，处于预告、试行、正式生效、发布还是复盘阶段”。然后从以下 7 类中选择最贴近的一类：

- `policy_rule`：平台商家规则、佣金/保证金/费率、算法机制、招商/托管政策，或国家电商监管/税务/消保新政
- `product_tool`：平台商家端/投放端新功能，或电商 SaaS、ERP、CRM、AI 电商工具的正式发布与重大升级
- `industry_event`：平台/头部品牌/服务商/MCN 财报、大促官方战报、投融资并购、高层人事、战略合作、物流供应链布局或合规处罚
- `data_report`：基于真实数据或调研的消费趋势、品类报告、渠道格局研究
- `playbook_method`：可复用的商家运营、投流、直播、内容种草、私域或 AI 提效实操方法
- `opinion_analysis`：一线操盘手、平台负责人、服务商或研究者的深度判断、战略解读与访谈
- `case_study`：具体的品牌/白牌突围案例、大促复盘或商业标杆拆解

### 二、按当前五轴独立打 0–10 整数分

1. `sig` 实质份量：它在国内电商大盘上是平台级规则拐点、本周值得记住的行业变化，还是局部小调整或日常脚注。
2. `nov` 信息增量：材料带来了多少明确的新规则、新数据、新工具能力或新打法，而不是把老常识换个标题重说一遍。
3. `cred` 证据强度：材料内部对核心事实提供了多强的支持，不是来源名气。官方规则公告足以证明“政策调整/工具上线”这一动作，但不能自动证明宣传中的 GMV 或 ROI 提升效果。
4. `reson` 共振面：多少品牌方/卖家操盘手、服务商、SaaS 或 MCN 读者会觉得这与自己的经营决策直接相关。
5. `act` 可操作性：商家或服务商是否能据此立刻调整选品、投流、合规动作、费用核算或工具栈。纯财报、并购与宏观行业事件的 act 低是正常的，不应反过来抹掉 sig。

### 三、使用以下类型权重合成分数

内部按下表计算 `attentionScore = sig×w1 + nov×w2 + cred×w3 + reson×w4 + act×w5`。每行权重之和为 10，所以结果天然位于 0–100。

不要把五轴先求平均；不要改权重；不要把多个普通理由堆成高分；不要为了靠近整十或任何想象中的门槛而改写计算结果。

## 品味规则

### 必须正常评价的价值

- 淘天、抖音、拼多多、京东、小红书、微信小店、快手、美团闪购等主流平台的规则、佣金/保证金、仅退款/售后机制、流量分发与广告投放机制发生清楚变化。
- 市场监管、税务、广告法、消保法等直接影响电商平台、商家、MCN 或直播带货合规的政策落地或重大执法结果。
- 平台商家工具、投放系统、SaaS/ERP 或 AI 电商工具在核心能力、费率、开放接口或适用商家范围上的实质升级。
- 头部平台、头部服务商或供应链网络发布的季度财报、618/双 11 战报、重大战略调整、物流费率或履约体系变革。
- 有真实投放数据、转化指标、成本结构或可迁移步骤支撑的品牌/卖家/MCN 实操复盘与趋势报告。
- 对纯出海/小众海外跨境平台（与国内供应链和国内盘无关）保持克制；但若涉及 Temu、SHEIN 等对国内产业带供货商规则、半托管/全托管结算产生直接影响，按其对国内商家生态的实际价值正常评分。

### 必须压住的噪声

- **品牌 PR 与软文通稿**：无具体 GMV、复购、成本、方法拆解的“某品牌亮相峰会/荣获大奖/发布新品理念”或服务商自我标榜案例，`sig ≤ 3` 且 `nov ≤ 3`。
- **卖课、卖群与招商广告**：以“揭秘月入百万打法”“加群领资料”“限时招募合伙人/代运营”为目的的引流文，`sig ≤ 2` 且 `act ≤ 2`。
- **消费者导购与单店促销**：面向消费者的好物清单、拼单优惠、单店折扣预告，`sig ≤ 2` 且 `reson ≤ 2`。
- **例行琐碎公告**：单个不知名类目的常规报名提醒、个别小店铺违规公示、日常界面微调、无实质权益变化的常规活动通知，`sig ≤ 3`。
- **情绪化水稿与无据传言**：只有“某平台要凉了”“卖家活不下去了”等情绪宣泄、洗稿拼接或无可靠信源支撑的江湖传言，`nov ≤ 3` 且 `cred ≤ 3`。
- **多事件大拼盘**：没有单一核心主线的周报汇总、行业杂谈合集，`sig ≤ 3`。
- **虚构或夸张战报**：只晒模糊截图、单一内部口径“暴涨 10 倍”而无基准基数与可验证上下文的营销战报，`cred ≤ 3`。

## 事件、转述与材料不足

- 不因为材料是行业媒体转述或二手报道就自动扣事件分。只要正文足以确认同一个具体事件，后续聚类会把它合并到更好的一手代表稿。
- 但不能把原文没有写出的GMV、同比增速、适用类目或政策生效时间补进事件。材料只能证明较弱主张时，`cred` 和相关轴必须随之降低。
- 如果标题与正文核心明显不符（典型标题党），或正文残缺到无法辨认主体、动作和阶段，最终分数不得高于 30。
- 如果只能确认“有传闻/有人声称某平台将调整政策”，却无法确认官方动作或具体口径，按这个较弱事件评分；不要替材料补全一个更强故事。

## 事件口径校正（与主规则一起执行）

下面规则用于纠正一个常见错误：把稿件的长短、作者口吻、是否引用，误当成事件本身的价值。若与前文的直觉判断发生冲突，以本节的事件口径为准，但五轴定义、类型权重和单字段输出契约不变。

1. 先把材料还原为最强且被正文支持的事件，再给五轴。不要给“这篇文章写得怎么样”打分。
2. 全平台覆盖面大的规则调整或能力开放本身是实质变化。哪怕公告篇幅很短（如百字商家公告调整基础软件服务费、取消或放宽仅退款、全面开放某流量入口），也不能因为篇幅短而压低 `sig`、`nov`、`reson`。
3. 同一材料同时包含强事件和弱叙事时，以强事件为核心分类和评分；例如“平台新规公布 + 作者主观吐槽”，不能只抓住吐槽身份把它压成水文。
4. 反过来，长篇大论、图表很多、语气专业，仍不能替一篇纯服务商软文、泛泛而谈的宏大叙事或重复老生常谈的方法论制造事件价值。只有正文支持的新事实、规则变化、真实数据或可迁移操作进入五轴。

完成上述校正后，仍严格按主规则的整数五轴与类型权重计算最终 `attentionScore`，不要额外加奖励分，也不要输出任何额外字段。
