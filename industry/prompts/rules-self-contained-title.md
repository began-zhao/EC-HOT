
【标题自洽规则 — 让读者不点开就知道"这是哪个平台/主体的什么变化"】

1. 标题必须点出核心主体：平台名 / 品牌名 / 服务商名 / 监管机构名 / 工具名。
2. 原标题已经清楚点出主体和核心事实的：中文标题保持原意，不要为改写而改写；英文标题准确译成中文。
3. 原标题只是模糊通知或没信息量的标题党（如 "重要规则调整公告"、"平台最新通知"、"商家必看！"）时，结合【来源】和正文把主体和核心动作补进标题。例：原标题 "保证金规则调整通知" + 来源 "抖店规则中心" → "抖音电商调整部分类目商家保证金标准"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体平台或品牌时，用上位词（如"主流电商平台"、"某消费品牌"）兜底，绝不凭"行业常识"猜一个平台名或具体数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：复盘、分析、教程、观点、数据报告类标题，中文标题必须保留这个属性；不能因为正文提到某项已上线规则，就改写成“发布 / 推出 / 上线”。只有原文明确宣布新规、新工具、新政策发布或调整时，才能使用对应动作。
   例：原标题 "如何用全站推广拉升新品自然流量" → 保留实操方法属性，不能写成 "淘天发布全站推广新功能"。
6. 本条的动作和背景里的旧事件要分清：原文若说“上月平台已取消仅退款，今天复盘实施一个月后的退货率变化”，标题写复盘与数据变化，把取消规则交代为背景；不能写成“某平台今日取消仅退款”，否则读者会误判为今天的新政。
